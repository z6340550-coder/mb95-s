MB95 Hafiz Kernel

MB95's own security-first microkernel, written in Rust.

It locks every app, driver and workspace in its own sealed space. Nothing touches your data, network or devices unless you allow it, so your privacy and data stay protected by design.

Get updates

Protected by design

Security is built into the base of the system, not added on top.

  • Microkernel

    The kernel keeps only the essentials. Drivers and services run outside it, each in its own space.

  • Sealed spaces

    Every app, driver and workspace is isolated from the others.

  • Permission first

    Access to your data, network and devices happens only when you allow it.

  • Written in Rust

    A language designed to prevent whole classes of memory errors.

  • Your data stays yours

    Privacy, protection and control, without compromise.

  • The base for MB95

    Planned as the foundation for Workdesk, replacing the Linux kernel it runs on today.
